# Splash asset credits

Made for this repo. Generated by the scripts in `tools/splash/` (see its README):

- `images/bge_cannon_*.webp` (`bge_cannon_hd.webp`, `bge_cannon_fhd.webp`) and `images/bge_cannonball_*.webp` (`bge_cannonball_hd.webp`, `bge_cannonball_fhd.webp`): drawn by `tools/splash/make_splash.py`.
- `bge_startup.wav`: synthesized from scratch by `tools/splash/make_sound.py` (no samples), downmixed to mono 22.05 kHz by `tools/splash/downmix.py`.
- `images/bge_title_*.webp`: also drawn by `make_splash.py`, set in Montserrat (SIL Open Font License 1.1); see `LICENSE-THIRD-PARTY.md` at the repo root.
